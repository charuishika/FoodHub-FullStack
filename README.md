# FoodHub – Full Stack Food Ordering Application

## Overview
FoodHub is a full-stack food ordering and restaurant management application that connects customers with restaurants. Customers can browse restaurants, view menus, add food items to their cart and place orders. Restaurant owners can manage their restaurants, menus and orders.

## Tech Stack

### Frontend
- React
- Vite
- Material UI
- React Router
- Axios
- Redux Toolkit
- React Context API

### API Gateway
- Node.js
- Express.js
- Axios

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication

### Databases
- MySQL
- MongoDB

## Features

### Customer
- Registration and login
- Browse and search restaurants
- View food menus
- Cart management
- Place orders
- View order history

### Restaurant Owner
- Restaurant management
- Add, edit and delete menu items
- Manage food availability
- View and manage orders
- Update order statuses

## Architecture

React Frontend → Node.js API Gateway → Spring Boot Backend → MySQL / MongoDB

## Security
- JWT authentication
- Role-based access control
- BCrypt password hashing
- Backend validation
- Idempotency protection for order creation
